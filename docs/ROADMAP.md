# Roadmap

Back to the [README](../README.md). Plans change with what players report; ideas are welcome as a feature request.

## Done

- **v0.1.0**: the game at any resolution in a borderless full-screen window or a resizable window, laid out for the screen; display scale and *Auto*; frames at the monitor's refresh rate and a steady game speed; a side panel modeled on Emperor's; smooth scrolling, city zoom and drag scrolling; the Options window, key rebinding and overlay keys; Esc and a Pause menu; sound improvements; city, minimap and screen screenshots; the adventure editor at your resolution.

## Planned

The order is not decided yet.

- **More information on the side panel**, in the space below it on taller screens.
- **A display scale for the interface only**, so the city can stay at its own size.
- **Extra keys** that neither game has, such as undo.
- **Right-click to cancel** while dragging out a building, as in Emperor.
- **Load and save windows of Pericles's own**, larger, with a preview of the saved city.
- **Raising the original's limits.**
- **Gameplay quality-of-life options** in the Options window, chosen with players' feedback.

See [CHANGELOG.md](../CHANGELOG.md) for each release in detail.

## Longer term

- **Localization**: UTF-8 translation files and a text engine with open-source fonts, starting with Traditional Chinese. The format will be open and documented, so the community can add **language packs** for other languages without changing the game's files.
- Fixing the original's bugs; better support for custom adventures.
- Smoother movement of people and animations between simulation steps.
- Eventually, a **reimplementation** that no longer needs the original executable.
